Minutes of the review board, 14 March

The board met to review three proposals for the annotation platform and to settle the open questions from February.

Proposal B: build on an existing library

Proposal B builds a new client on an existing library and writes the server fresh. The library handles selection and highlighting; its re-anchoring is position based and would need a quote fallback. Five members supported it, with the condition that the fallback is tested on real pages before the decision is final.

Proposal C: copy the anchoring code

Proposal C copies the anchoring code from the existing client and builds everything else new. It is the most work up front but leaves nothing to an upstream project. Two members supported it.

Access control

Every proposal must support per-annotation permissions: read, update, delete and share, enforced in search as well as on single items. The chair asked for a written model by the next meeting.

Decisions

  1. Run a two-week trial of Proposals B and C on a corpus of real pages.
  2. Record the result as an architecture decision.

The meeting closed at 16:40.
