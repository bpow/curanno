Release notes for version 3.2

Version 3.2 is a maintenance release. It fixes the crash on startup when the configuration file is missing, and it adds a --dry-run flag to the importer.

Addresses may now be written on two lines:
Flat 4, 12 Harbour Street
Kingstown

The API gains a /health endpoint. ★ Clients should poll it no more than once a minute.

Known issues

Exporting to PDF loses footnotes on pages with rotated tables. A fix is planned for 3.2.1.

Upgrading

Back up the database before upgrading. The migration renames the owner column to created_by and cannot be reversed automatically.
